# Калькулятори для живностника

## Структура — заливати ТОЧНО так

```
корінь репозиторію/
├── index.html          ← головна з вибором
├── dane/
│   ├── index.html
│   ├── manifest.json
│   ├── sw.js
│   ├── icon-192.png
│   ├── icon-512.png
│   └── icon-maskable.png
└── ipoteka/
    ├── index.html
    ├── manifest.json
    ├── sw.js
    ├── icon-192.png
    ├── icon-512.png
    └── icon-maskable.png
```

**Важливо:** папки `dane` і `ipoteka` мають бути саме папками. Файли всередині названі однаково в обох — це нормально, вони в різних папках.

## Адреси після заливки

- Головна: `https://твій-юзер.github.io/репо/`
- Податки: `https://твій-юзер.github.io/репо/dane/`
- Іпотека: `https://твій-юзер.github.io/репо/ipoteka/`

## Встановлення на телефон

Кожен калькулятор ставиться окремо:

1. Відкрий `/dane/` у Chrome → меню (⋮) → «Додати на головний екран» → іконка **Податки**
2. Відкрий `/ipoteka/` у Chrome → те саме → іконка **Іпотека**

Тепер вони встановляться як два різні застосунки, бо лежать у різних папках (різний scope).

## Оновлення

Коли міняєш калькулятор — піднімай версію в його `sw.js`:

```js
const CACHE = 'dane-v1';   // → 'dane-v2'
```

Інакше телефон віддаватиме стару копію з кешу.

## Дані

Все зберігається локально на твоєму пристрої (localStorage). Нікуди не передається.
