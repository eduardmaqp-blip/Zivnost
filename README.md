# Калькулятори — PWA

Два калькулятори для живностника, працюють як застосунки на телефоні.

## Файли (всі в корінь репозиторію)

| Файл | Що це |
|---|---|
| `index.html` | Стартова сторінка з вибором |
| `dane-odvody.html` | Калькулятор податків |
| `ipoteka-v2.html` | Калькулятор іпотеки |
| `manifest-dane.json` | Маніфест першого застосунку |
| `manifest-ipoteka.json` | Маніфест другого застосунку |
| `sw.js` | Service worker (офлайн-робота) |
| `icon-*.png` | Іконки (6 файлів) |

## Як залити на GitHub Pages

1. Заливаєш **усі файли в корінь** репозиторію (не в підпапку)
2. Settings → Pages → Source: `main` / `root`
3. Чекаєш 1-2 хвилини, поки збереться

## Як встановити на Android

1. Відкрий сторінку в **Chrome** (не в іншому браузері)
2. Меню (три крапки) → **«Додати на головний екран»** або «Встановити застосунок»
3. З'явиться іконка на робочому столі

Кожен калькулятор встановлюється окремо:
- зайди на `dane-odvody.html` → встанови → буде іконка «Податки»
- зайди на `ipoteka-v2.html` → встанови → буде іконка «Іпотека»

## Як встановити на iPhone

Safari → кнопка «Поділитись» → «На екран Home»

## Офлайн

Після першого відкриття все працює без інтернету — файли зберігаються в кеші телефону.

## Оновлення

Коли міняєш калькулятори, **обов'язково зміни версію** в `sw.js`:

```js
const CACHE = 'kalkulacky-v1';   // → 'kalkulacky-v2'
```

Інакше браузер віддаватиме стару версію з кешу.

## Дані

Все вводиться і зберігається **локально на твоєму телефоні** (localStorage). Нікуди не передається, сервера немає. Хто інший відкриє посилання — побачить порожній калькулятор.
